# Walks

Scripts for a person to walk a journey on a device, where `make e2e` can only cover the web. Each is a table of who to sign in as, what to do and what to expect, for the web, the iOS simulator and the Android emulator. They are written to be followed by hand; the web half is also what [e2e](../../e2e/README.md) runs.

| Walk | Journey |
|---|---|
| [core-loop.md](core-loop.md) | Journey 1: from a join link to feedback, three people in one outing |

Keep a walk in step with its journey in `e2e/tests/`: a change to one is a change to the other.
