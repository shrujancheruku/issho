# Security policy

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub: **Security → Report a vulnerability** on this repository. Include steps to reproduce and the impact. We aim to acknowledge reports within 3 business days.

## Leaked secrets

If you find a credential in this repository or its history, report it privately as above. Maintainers: follow the response steps in [docs/secrets.md](docs/secrets.md#if-a-secret-leaks), starting with rotating the credential.

## Supported versions

Issho is pre-1.0. Only the latest release on `main` receives fixes.
